# 阳光收集站 · 阳光驿站留言板

🔗 在线体验：<https://yskm-77.github.io/sunny-station/>

计算机科学与技术学院阳光驿站「心理专属空间——Web 开发」活动作品，方向为**驿站留言页**。

一个暖色调的留言板：先选一个心情，再写下想说的话，让它被看见。所有留言只保存在浏览器本地，不上传服务器。

## 亮点

- **首屏阳光动画**：缓慢旋转的光芒、呼吸的太阳、漂浮的光点与流动的云
- **心情选择**：开心 / 平静 / 期待 / 疲惫 / 有点焦虑 / 想倾诉，每条留言带专属心情颜色
- **实时预览**：右边同步显示你的留言卡片
- **留言墙**：类别筛选、关键词搜索、按最新或最暖排序
- **送阳光**：给喜欢的留言点一颗小太阳，可再点一次收回
- **每日一句**：随机换一句温柔的话
- **导出 JSON**：把本机留言打包交给驿站汇总
- **细节**：滚动渐入、提交时的光点爆开、字数进度条、吸顶导航、移动端适配、`prefers-reduced-motion` 降级

## 技术

- 手写 HTML / CSS / JavaScript，无框架、无第三方库、无网络请求
- 数据保存在 `localStorage`
- 滚动出现用 `IntersectionObserver`；动画全部由 CSS 与少量 JS 完成
- 图形均为内联 SVG 与 CSS 绘制，未使用任何图片
- 使用系统字体，不加载外部字体

## 目录

```
sunny-deluxe/
├── index.html      页面结构
├── css/style.css   全部样式与动画
├── js/app.js       留言逻辑、筛选、排序、送阳光、导出
└── README.md
```

## 本地打开

双击 `index.html` 即可；若浏览器限制 `file://`，可在目录下运行：

```bash
python -m http.server 8000
```

然后访问 <http://localhost:8000>。

## 素材与隐私

- 没有使用任何网络图片、图标库或字体文件
- 留言与联系方式仅写入本机 `localStorage`，换设备或清除数据后不会保留
- 页面不含统计脚本与第三方请求
