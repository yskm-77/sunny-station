# 阳光驿站留言板

🔗 在线体验：<https://yskm-77.github.io/sunny-station/>

这是计算机科学与技术学院阳光驿站「心理专属空间——Web 开发」活动的作品，我做的是一个简单的留言板：同学们可以在上面给驿站提建议。

## 功能

- 填写昵称（可以不填）、选择类别、写留言内容
- 提交后留言显示在下方列表里
- 可以删除自己写错的留言
- 刷新页面后留言还在（存在浏览器本地）
- 字数限制 300 字，有实时字数统计

## 用到的技术

- HTML + CSS + JavaScript，全部写在一个 `index.html` 文件里
- 用 `localStorage` 保存留言
- 没有使用框架，没有使用第三方库
- 没有用图片，页面上的样式都是 CSS 写的

## 怎么打开

- 直接双击 `index.html` 用浏览器打开
- 或者访问线上地址：<https://yskm-77.github.io/sunny-station/>

## 说明

留言只保存在访问者自己的浏览器里，不会上传到服务器，换电脑或清除浏览器数据后就看不到了。
