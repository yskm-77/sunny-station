About

关于这个小站

这是阳光驿站「心理专属空间——Web 开发」活动的作品。我们想做的不只是一个页面，而是一个愿意听人说话的小角落。

没有后端、没有第三方统计，留言只属于写下它的人。

素材与实现

  • 手写 HTML / CSS / JavaScript，无框架、无第三方库
  • 所有图形为内联 SVG 与 CSS 绘制，无网络图片
  • 使用系统字体，不加载外部字体
  • 数据仅保存在浏览器 localStorage
