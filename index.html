    关于这个小站

    这是计算机科学与技术学院阳光驿站「心理专属空间——Web 开发」活动的参与作品，选择的方向是驿站留言页：把“建言献策”做成一个真正能用的轻量工具，而不是一张静态海报。

    页面不依赖任何后端与第三方脚本，所有数据都留在你自己的浏览器里。评审或驿站需要汇总时，可以用「导出 JSON」把本机留言交给负责人。

    素材与实现说明

    • 代码：手写 HTML / CSS / JavaScript，无框架、无第三方库。
    • 图形：全部为内联 SVG 与 CSS 绘制，未使用任何网络图片。
    • 字体：使用系统字体（苹方、微软雅黑、思源黑体等），不加载外部字体文件。
    • 数据：仅保存在浏览器 localStorage，不上传、不统计。

    隐私说明

    留言与联系方式只写入本机 localStorage；清除浏览器数据、换浏览器或换设备都不会同步。请在提交前自行确认内容。
